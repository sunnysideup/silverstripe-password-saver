# Upgrade to Silverstripe CMS 6

## Requirements

- ⚠️ **BREAKING CHANGE:** Silverstripe support is now `silverstripe/framework: ^6.0` only. Support for `^4.0` and `^5.0` is dropped. Stay on the previous release of this module if you are on SS4 or SS5.

**🚨 CRITICAL REVIEW REQUIRED: `composer.json` does not declare `sunnysideup/uudi`, but the code uses `Sunnysideup\UUDI\Api\HashCreator`. Add `sunnysideup/uudi` to `require` with an SS6-compatible version, and confirm that version installs. Otherwise the class will be missing at runtime.**

## API changes

### `ClientSidePasswordField`

- ⚠️ **BREAKING CHANGE:** `Value()` is replaced by `getFormattedValue()`. Update any subclass overrides of `Value()`, and any code that calls `->Value()` on this field, to use `getFormattedValue()`.
- Constructor signature is now `__construct($name, $title = null, $value = null, ?string $link = null)`. The `$link` type is now explicitly nullable. Callers don't need to change. Subclasses that override the constructor must use the same signature.

### `DBClientSidePassword`

- ⚠️ **BREAKING CHANGE:** `forTemplate()` now declares a `: string` return type. Add the same return type to any subclass override.
- ⚠️ **BREAKING CHANGE:** `saveInto($dataObject)` now declares a `: void` return type. Add the same return type to any subclass override.

## Security

**🚨 CRITICAL REVIEW REQUIRED: `ClientSidePasswordField` outputs `$value` and `ManagerLink` into HTML without escaping. The value is generated by the module, but that is not guaranteed. Escape both before output, for example with `Convert::raw2att()`.**

**🚨 CRITICAL REVIEW REQUIRED: `DBClientSidePassword::formInner()` outputs `$link` and `$this->value` into HTML without escaping. Wrap both in `Convert::raw2att()`.**

These issues are not fixed by this upgrade. They are recorded in `docs/en/FINAL_REVIEW.md`.

## Housekeeping

- `.agents/` is now git-ignored.
